# 首页装修模块产品设计说明

> 模块状态：服务端与 B 端已实现；C 端首页待接入

## 1. 模块定位、目标与非目标

首页装修模块让运营人员维护小程序首页的 Banner、公告和品牌背书内容，并向 C 端提供一次性聚合的有效内容。

目标：

- 运营人员可独立维护三类首页内容。
- C 端只获取启用的 Banner 与公告。
- 支持排序、上下线和安全保留历史记录。

非目标：

- 当前不是自由拖拽装修器，不支持组件编排或页面版本。
- 不支持定时发布、人群定向、A/B 测试或预览发布流程。
- Banner 跳转后的具体页面业务归对应目标模块。

## 2. 用户角色、场景与端侧范围

| 角色         | 使用场景                     | 当前支持                       |
| ------------ | ---------------------------- | ------------------------------ |
| 游客/会员    | 查看首页轮播、公告和品牌内容 | 聚合能力已实现，C 端页面待接入 |
| 内容运营人员 | 维护 Banner、公告和品牌背书  | B 端已实现                     |

## 3. 核心业务对象与术语

- **Banner**：首页轮播图片，可配置一个可选跳转地址。
- **公告**：由标题和正文组成的首页通知内容。
- **品牌背书**：一份全局富文本品牌介绍内容。
- **启用状态**：控制 Banner 或公告是否进入 C 端首页聚合结果。
- **排序值**：数值越小，内容在同类列表中越靠前。

## 4. 功能清单

### 4.1 B 端 Banner

- 分页查看图片、跳转地址、排序、状态和创建时间。
- 按启用或禁用状态筛选。
- 新增、编辑、启用、禁用和删除 Banner。
- 上传或选择图片，配置可选站内路径或完整地址。

### 4.2 B 端公告

- 按标题关键字和状态筛选公告。
- 查看标题、正文、排序、状态和创建时间。
- 新增、编辑、启用、禁用和删除公告。

### 4.3 B 端品牌背书

- 查看当前全局品牌内容。
- 使用富文本编辑并保存一份品牌背书。

### 4.4 C 端首页内容

- 公开获取所有启用 Banner、启用公告和品牌背书。
- Banner 与公告分别按排序值升序展示。
- 未配置品牌内容时返回空内容，不阻断首页其他区域。

## 5. 关键用户流程

### 5.1 发布 Banner 或公告

1. 内容运营人员新增内容并填写必需信息。
2. 设置排序值和启用状态。
3. 保存后，启用内容进入 C 端首页聚合结果。
4. 禁用内容仍保留在后台，但不再向 C 端展示。
5. 删除内容后，后台和 C 端均不再展示该记录。

### 5.2 C 端加载首页

1. 用户进入首页。
2. C 端一次获取 Banner、公告和品牌内容。
3. 页面分别渲染轮播、公告区域和品牌区域。
4. 某一类内容为空时，只隐藏或显示该区域的空状态，不影响其他内容。

## 6. 业务规则与状态

### 6.1 Banner

- 图片地址必填，跳转地址可选。
- 跳转地址只负责保存，C 端需要自行判断站内路径或完整地址并执行安全跳转。
- 排序值不能为负数。
- 启用内容才进入 C 端聚合结果。

### 6.2 公告

- 标题和正文必填。
- 标题最长 100 个字符，正文最长 10000 个字符。
- 公告没有独立详情状态、阅读状态或发布时间范围。
- 启用公告按排序值升序展示。

### 6.3 品牌背书

- 全系统只维护一份当前品牌背书。
- 品牌内容可为空，保存新内容会覆盖当前版本。
- 当前不保留可供运营回退的历史版本。

### 6.4 状态

| 状态   | B 端             | C 端         |
| ------ | ---------------- | ------------ |
| 启用   | 可查看和编辑     | 参与首页展示 |
| 禁用   | 可查看和编辑     | 不展示       |
| 已删除 | 不在正常列表展示 | 不展示       |

## 7. 权限与数据可见范围

- C 端首页内容为公开信息，不要求登录。
- Banner、公告和品牌的查看、创建、编辑、状态修改和删除由后台权限分别控制。
- 品牌背书富文本应仅由可信运营人员维护。

## 8. 异常与边界场景

| 场景                     | 处理                                          |
| ------------------------ | --------------------------------------------- |
| Banner 未提供图片        | 拒绝保存                                      |
| 排序值为负数             | 拒绝保存                                      |
| 公告标题或正文为空       | 拒绝保存                                      |
| 查询或编辑不存在的内容   | 提示对应内容不存在                            |
| 没有任何启用 Banner/公告 | C 端返回空列表，首页其他内容继续加载          |
| 品牌内容尚未配置         | 返回空品牌内容                                |
| Banner 跳转目标失效      | 当前由 C 端跳转处理，模块本身不校验目标可达性 |

## 9. 模块联动

- 文件上传能力为 Banner 图片和富文本素材提供地址。
- Banner 跳转可指向[商品](./02-product.md)、[预约](./07-appointment.md)、[拼团](./09-group-buy.md)或其他已注册页面。
- [经营看板](./11-dashboard.md)当前不统计 Banner 点击或公告阅读。

## 10. 当前覆盖与已知缺口

| 能力         | 服务端 | B 端   | C 端       |
| ------------ | ------ | ------ | ---------- |
| Banner 管理  | 已实现 | 已接入 | 首页待接入 |
| 公告管理     | 已实现 | 已接入 | 首页待接入 |
| 品牌背书     | 已实现 | 已接入 | 首页待接入 |

已知缺口：小程序首页仍为占位页面；当前没有装修预览、定时上下线、内容版本、点击统计和跳转目标自动校验。

## 11. 验收标准

- **Given** 一个启用和一个禁用 Banner，**When** C 端加载首页，**Then** 只返回启用 Banner。
- **Given** 多个启用公告排序值不同，**When** 加载首页，**Then** 按排序值从小到大展示。
- **Given** 运营人员禁用一条公告，**When** C 端再次加载，**Then** 该公告不再出现且后台记录仍保留。
- **Given** 品牌内容未配置，**When** 加载首页，**Then** 品牌内容为空但 Banner 和公告正常返回。
- **Given** 运营人员没有对应编辑权限，**When** 修改装修内容，**Then** 操作被拒绝。
