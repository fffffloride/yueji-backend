# 预约模块产品设计说明

> 模块状态：最简预约服务端与 B 端已实现；C 端页面待接入

## 1. 模块定位、目标与非目标

预约模块当前提供“会员选择未来日期和固定时间段并提交”的最简预约能力，并以可配置的统一容量防止时间段超额。

目标：

- 已登录会员可提交一个合法的未来预约时间段。
- 避免同一会员对同一日期和时间重复提交。
- 默认每个日期和时间段最多接受 1 位客户，运营人员可修改统一上限。
- 后台可按会员或日期查询预约记录。

非目标：

- 当前不包含医生、门店、项目、商品、订单、排班或独立号源。
- 当前不包含预约状态、确认、到店、取消、改期或通知。
- 小程序占位页中出现的完整预约设想不代表已实现能力。

## 2. 用户角色、场景与端侧范围

| 角色         | 使用场景                       | 当前支持                   |
| ------------ | ------------------------------ | -------------------------- |
| 会员         | 选择日期和时间，提交预约意向   | 能力已实现，C 端页面待接入 |
| 预约运营人员 | 查看预约记录并配置时段容量     | B 端已实现                 |

## 3. 核心业务对象与术语

- **预约记录**：某会员提交的预约日期、预约时间和提交时间。
- **重复预约**：同一会员对同一天、同一时间再次提交。
- **时段容量**：同一日期和时间段允许保存的最大客户数，对全部时段统一生效。
- **预约意向**：当前记录不包含确认状态，只表示会员选择并提交了一个未来时间。

## 4. 功能清单

### 4.1 B 端

- 分页查看预约 ID、会员昵称、手机号、预约日期、预约时间和提交时间。
- 按会员昵称或手机号关键字筛选。
- 按指定预约日期筛选。
- 查看和修改每时段统一预约上限。
- 不提供预约记录新增、编辑、取消、确认或删除操作。

### 4.2 C 端

- 已登录会员提交预约日期和预约时间。
- 已登录会员可查询指定日期的 9 个时间段、剩余数和可用状态。
- 成功后返回本次预约记录。
- 当前没有“我的预约”查询能力。

## 5. 关键用户流程

1. 会员登录后进入预约入口。
2. 选择一个晚于当前时间的日期和时间。
3. 系统校验日期、时间格式及是否为未来时间。
4. 系统检查本人是否已提交相同日期和时间，以及目标时间段是否已满。
5. 系统在事务内锁定容量配置，校验通过后保存预约意向。
6. 运营人员在后台预约列表中查看该记录。

## 6. 业务规则与状态

- 日期格式固定为年-月-日；可预约时间为每天 `10:00–18:00` 的 9 个整点。
- 预约时间必须严格晚于提交时的当前时间。
- 同一会员不能重复提交完全相同的日期和时间。
- 容量默认为 1 且只允许正整数；不同会员选择同一日期和时间时共享该容量。
- 配置调低不删除已有预约；已有数量大于或等于新上限时立即视为已满。
- 同一会员可以提交不同日期或不同时间的多条预约。
- 当前预约记录没有业务状态，保存后仅作为只读记录存在。
- 后台列表按预约日期、时间和记录顺序从新到旧展示。

## 7. 权限与数据可见范围

- C 端提交预约必须是已登录会员，会员身份由系统从当前会话确定。
- 会员不能代替其他会员提交预约。
- B 端预约列表需要预约查询权限。
- B 端修改容量需要预约配置权限。
- 当前 C 端没有读取本人历史预约的入口。

## 8. 异常与边界场景

| 场景                       | 处理                             |
| -------------------------- | -------------------------------- |
| 日期格式或时间段错误       | 拒绝提交并提示选择有效时间段       |
| 预约时间等于或早于当前时间 | 拒绝提交并提示不能早于当前时间   |
| 同一会员重复提交相同时间   | 拒绝提交并提示该时间已预约       |
| 多位会员并发提交相同时间 | 仅允许写入至容量上限，其余返回已约满 |
| 其他会员选择已满时间       | 拒绝提交并提示选择其他时间       |
| 会员希望取消或改期         | 当前无对应能力，需要人工沟通处理 |

## 9. 模块联动

- [会员模块](./01-member.md)提供预约主体以及后台展示所需的昵称和手机号。
- [经营看板](./11-dashboard.md)把新增预约纳入系统动态。
- 当前不与[商品](./02-product.md)、[订单](./04-order.md)或医生排班关联。

## 11. 验收标准

- **Given** 已登录会员选择合法未来时间，**When** 提交预约，**Then** 保存本人预约记录并可在后台查询。
- **Given** 会员选择过去时间，**When** 提交，**Then** 系统拒绝且不产生记录。
- **Given** 会员已有同日同时间预约，**When** 再次提交，**Then** 明确提示重复预约。
- **Given** 容量为 1 且一名会员已预约某时间，**When** 其他会员提交同一日期和时间，**Then** 系统拒绝并提示已约满。
- **Given** 运营人员将容量改为 3，**When** 不同会员提交同一时间，**Then** 最多保存 3 条有效预约。
- **Given** 运营人员没有预约查询权限，**When** 打开预约列表，**Then** 操作被拒绝。
