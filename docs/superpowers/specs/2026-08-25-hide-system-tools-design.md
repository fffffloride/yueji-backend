# 隐藏系统工具菜单设计

## 目标

从管理端侧边栏隐藏字典管理、系统日志、系统配置和通知公告，同时保留其数据、接口、权限与隐藏路由，避免影响现有业务。

## 影响与边界

- 系统配置仍为积分规则等业务提供配置值，只隐藏管理入口。
- 系统日志继续记录，并继续作为仪表盘系统动态的数据来源。
- 字典接口继续为性别、通知类型和通知等级等组件提供选项。
- 通知公告继续支持顶部通知铃铛、个人通知和仪表盘动态；隐藏后仍可通过直接地址进入管理页。
- 不删除页面、模块、数据表、角色权限或历史数据。

## 实现

将 `sys_menu` 中以下菜单的 `visible` 设为 `0`：

| ID | 菜单 |
| --- | --- |
| 250 | 字典管理 |
| 260 | 系统日志 |
| 270 | 系统配置 |
| 280 | 通知公告 |

保留子菜单和按钮权限。后端路由构建会继续注册 `visible=0` 的菜单，并以隐藏标记返回，因此直接地址仍可访问。

同时：

1. 修改基础初始化 SQL，使新环境默认隐藏。
2. 增加可重复执行的现有数据库更新脚本。
3. 在本机数据库执行更新脚本。

## 验证

- 查询四条菜单记录，确认 `visible=0`。
- 确认对应按钮权限和接口未删除。
- 确认管理端路由仍返回这些菜单，但标记为隐藏。
- 执行 SQL 静态检查与仓库差异检查。

菜单数据在登录时加载，已登录用户刷新页面或重新登录后生效。
