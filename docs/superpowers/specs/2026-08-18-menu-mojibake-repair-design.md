# 后台菜单乱码修复设计

## 问题

`sys_menu` 中 18 条阶段 3/5 菜单名称已被错误转码后写入数据库。数据库、连接和表均使用 `utf8mb4`，前端只是原样显示接口返回值。

## 修复

在一个事务中按菜单 ID 更新这 18 条记录的 `name`。正确名称直接取自仓库现有的 `sql/mysql/menu_order.sql` 和 `sql/mysql/menu_marketing.sql`；不修改菜单 ID、路由、权限、前端代码或字符集配置。

## 验证

更新后查询 18 条记录并与 SQL 源值逐项比较，再刷新管理端，确认“会员等级”“营销管理”“积分管理”“优惠券管理”等菜单正常显示。

若事务执行或校验失败，则回滚，不留下部分更新。
