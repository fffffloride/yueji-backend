# 协议管理设计

日期：2026-08-30  
状态：待实现

## 1. 目标

为悦己小程序提供可由管理后台维护的用户协议和隐私政策，形成“后台编辑草稿 → 发布 → 小程序公开读取”的最小闭环。

本次固定支持两种协议：

- 用户协议：`USER_AGREEMENT`
- 隐私政策：`PRIVACY_POLICY`

不实现自定义协议类型、删除协议、历史版本、定时发布、多语言或用户签署记录。

## 2. 方案

新增独立协议模块，不复用通知公告或系统配置：

- 通知公告包含目标用户、已读和撤回语义，与法律协议不一致。
- 系统配置现有字段和表单过短，也没有草稿与发布边界。
- 独立模块只维护两条固定记录，接口和权限边界清楚。

## 3. 数据模型

新增 `agreement` 表，每种协议固定一条记录，`type` 唯一：

| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `type` | 协议类型，唯一 |
| `draft_title` | 草稿标题 |
| `draft_content` | 草稿富文本正文，`text` |
| `published_title` | 当前已发布标题，可空 |
| `published_content` | 当前已发布富文本正文，`text`，可空 |
| `publish_time` | 最近发布时间，可空 |
| 通用审计字段 | 创建/更新人、时间、逻辑删除 |

迁移脚本预置用户协议和隐私政策两条记录。编辑只更新草稿字段；发布在事务内把草稿标题和正文复制到已发布字段并更新时间。再次编辑草稿不会影响线上内容。

## 4. 服务端

### 4.1 管理端接口

接口使用现有 B 端 JWT 与 RBAC：

- `GET /api/v1/agreements`：返回两种协议的标题、发布状态、更新时间和发布时间。
- `GET /api/v1/agreements/:type/form`：返回指定协议的草稿表单。
- `PUT /api/v1/agreements/:type`：保存草稿标题和正文。
- `PUT /api/v1/agreements/:type/publish`：发布当前草稿。

权限：

- `content:agreement:list`
- `content:agreement:update`
- `content:agreement:publish`

协议类型只接受两个固定枚举；标题和正文必填，正文发布前再次校验非空。不提供新增和删除接口。

### 4.2 小程序公开接口

- `GET /api/v1/app/agreements/:type`

公开接口只返回 `type`、已发布标题、已发布正文和发布时间。尚未发布时返回明确业务错误“协议暂未发布”，不回退草稿。

富文本来自受 RBAC 保护的后台编辑器，小程序使用 uni-app 原生 `rich-text` 渲染，不在页面执行脚本。

## 5. 管理端

在“内容管理”下增加“协议管理”菜单。页面固定展示两行：用户协议、隐私政策。

每行展示：

- 协议类型
- 草稿标题
- 发布状态
- 最近编辑时间
- 最近发布时间
- 编辑、发布操作

编辑使用现有 `WangEditor`，弹窗包含标题和正文。保存只保存草稿；发布前二次确认，成功后刷新列表。不增加新建、删除、批量操作和分页。

权限按钮沿用 `v-hasPerm`。

## 6. 小程序

复用现有 `pages-sub/common/agreement/index` 页面，通过查询参数区分协议：

- `type=USER_AGREEMENT`
- `type=PRIVACY_POLICY`

页面加载公开接口并展示：

- 加载态
- 协议标题与发布时间
- 富文本正文
- 加载失败/未发布状态与重试按钮

加载成功后动态设置原生导航栏标题。非法或缺失的 `type` 默认按用户协议处理，兼容现有 `RoutePath.AGREEMENT`。

登录页勾选区同时展示《用户协议》和《隐私政策》，分别进入同一详情页的不同类型。用户仍需勾选后才能登录；本次不新增服务端签署记录。

## 7. 异常与一致性

- 草稿保存失败：保留编辑弹窗内容并显示统一错误。
- 发布失败：保留旧的已发布内容，事务不产生半发布状态。
- 小程序接口失败：不展示草稿或旧页面硬编码正文，显示错误与重试。
- 协议正文为空：管理端禁止发布。
- 已发布协议再次编辑：线上继续读取上一次已发布内容，直到下一次发布。

## 8. 验收

### 服务端

- 两种协议初始化存在且类型不可新增、删除或改名。
- 保存草稿不改变公开接口内容。
- 发布后公开接口返回最新发布内容。
- 空标题、空正文、非法类型和未发布读取都有明确错误。
- 未授权用户不能访问管理端接口，公开接口无需登录。

### 管理端

- 固定两行展示，无新增和删除入口。
- 用户协议和隐私政策可以分别编辑、保存草稿和发布。
- 发布二次确认有效，权限按钮正确。

### 小程序

- 登录页两个协议链接跳转正确。
- 两种协议均能展示标题、发布时间和富文本正文。
- 未发布、网络失败和重试状态可见。
- `pnpm type-check` 与微信小程序构建通过。
