# 移除管理端模板演示模块设计

## 目标

永久移除「组件封装、功能演示、多级菜单、路由参数」四组模板演示模块，使当前数据库和以后新建环境都不再出现这些菜单。

## 范围

- 管理端删除四组 Mock 菜单数据、全部纯演示页面，以及只服务于多级菜单演示的详情静态路由。
- 服务端初始化 SQL 删除四组菜单、子菜单和对应角色授权。
- 新增可重复执行的 SQL，先删除对应角色菜单关联，再删除现有数据库中的四棵菜单树。
- 保留业务页面正在使用的上传、富文本、字典等共享组件。
- 保留菜单系统的通用路由参数字段与动态路由处理能力。

## 数据流

登录后菜单仍由服务端 `sys_menu` 动态下发。清理现有数据库后，四组菜单不会进入前端路由；新环境使用已清理的初始化 SQL，也不会创建它们。Mock 模式使用已清理的 Mock 数据，行为保持一致。

## 安全与兼容

清理 SQL 只匹配四个已确认的顶级菜单 ID 及其 `tree_path` 后代，先删除 `sys_role_menu` 引用，再删除 `sys_menu`，避免外键或孤儿授权。脚本可重复执行。共享组件和系统路由能力不在删除范围内。

## 验证

- 全仓搜索确认四个菜单名、演示路由和 `demo/` 页面引用无业务残留。
- 运行管理端类型检查和生产构建。
- 检查清理 SQL 的目标 ID 与初始化 SQL 一致。
