# 移除登录页辅助登录功能设计

## 目标

管理端登录页仅保留账号密码、验证码和记住我，完整移除忘记密码占位功能、统一认证入口及扫码登录前后端链路。

## 管理端

- 删除忘记密码入口、页面组件及表单切换状态。
- 删除“其他登录方式”、统一认证按钮和扫码登录组件。
- 删除扫码登录 API、用户状态方法、二维码依赖和无用样式、类型、图标引用。
- 保留现有账号密码登录、验证码刷新、记住我、主题切换和登录跳转逻辑。

## 后端

- 删除扫码登录控制器路由、服务及模块注册。
- 删除扫码登录专用认证方法、用户查询辅助方法、错误码和 Redis Key。
- 不修改普通账号密码、短信及小程序微信登录接口。

## 验证

- 扫描确认无忘记密码、其他登录方式和扫码登录功能引用。
- 管理端类型检查与生产构建、后端生产构建通过。
- 重启后端，确认验证码和账号密码登录正常，旧扫码接口返回 404。
