# 协议管理实施计划

## 目标

完成用户协议和隐私政策的后台草稿/发布、小程序公开读取与登录页双链接。

## 任务 1：服务端与 SQL

- 新增 `agreement` 实体、枚举、DTO、服务、B 端控制器、C 端公开控制器与模块。
- 在 `AppModule` 注册模块。
- 新增 `sql/mysql/biz_agreement.sql`，创建表并预置两种协议。
- 在现有“页面管理”菜单下增加“协议管理”与查询、编辑、发布权限，授权角色 1、2。
- 增加服务层最小测试：保存草稿不影响公开内容、发布复制草稿、空正文禁止发布。

## 任务 2：管理端

- 新增 `src/api/agreement` 类型与四个请求。
- 新增 `src/views/decoration/agreement/index.vue`。
- 固定两行展示，不做分页、新增或删除。
- 编辑弹窗复用 `WangEditor`；保存草稿与发布分别操作，发布二次确认。

## 任务 3：小程序

- 新增 `src/api/agreement` 公开读取接口与类型。
- 将协议占位页替换为加载、错误、重试和 `rich-text` 正文展示。
- 复用现有协议路由，以 `type` 查询参数区分用户协议和隐私政策。
- 登录页保留合并前样式，增加隐私政策链接并为两个链接传入不同类型。

## 任务 4：验证

- 服务端：协议单测、lint、build。
- 管理端：type-check、lint 或 build。
- 小程序：type-check、H5 与微信小程序构建。
- 核对三个仓库差异，只提交本功能文件；保留小程序现有“我的/登录回滚”工作区改动归属。
