# 我的预约、取消与改期实施计划

设计依据：`docs/superpowers/specs/2026-09-02-appointment-lifecycle-design.md`

## 任务 1：服务端状态模型与开发迁移

- 新增预约状态常量和操作日志实体。
- 扩展预约实体的状态、完成时间、取消时间与取消原因。
- 用生成列唯一索引替换现有两个全量唯一索引；容量查询只统计 `BOOKED`。
- 新增 `sql/mysql/appointment_lifecycle.sql`，只清理预约域开发测试数据并升级结构。
- 同步 `sql/mysql/biz_phase6.sql`、测试种子和预约产品设计文档。

## 任务 2：服务端 C 端查询与动作

- 增加个人预约统计和四类分页 DTO、接口与聚合查询。
- 扩展创建事务，写入创建日志并允许取消后的订单重新预约。
- 增加会员取消与改期接口；校验归属、状态、开始时间、固定时段和容量。
- 返回服务端计算的 `canBook/canCancel/canReschedule`，前端不自行推导。
- 扩展订单分页与详情，返回最小预约摘要和 `canBookAppointment`。

## 任务 3：服务端后台与订单联动

- 后台分页增加四类数据、场景、日期范围、订单号与会员筛选。
- 增加后台统计、时段、详情、改期、取消和面诊完成接口。
- 增加改期、取消、完成权限及菜单 SQL。
- 订单核销事务同步完成订单预约；退款事务幂等取消待到店预约。
- 扩展预约和订单测试，覆盖重约、并发、容量释放、权限与联动；运行 Jest 和构建。

## 任务 4：小程序统一预约抽屉

- 将现有创建预约页面提取为 `YjAppointmentDrawer`，使用现有底部 Popup。
- 支持面诊创建、订单创建和改期三种上下文。
- 接入首页、支付结果、订单卡片和待预约卡片；登录回跳后恢复抽屉上下文。
- 成功后按来源刷新并提供“查看我的预约”。

## 任务 5：小程序“我的预约”与个人中心

- 将 TabBar 预约页改为四 Tab 的“我的预约”，接入统计与分页。
- 实现待预约、待到店、服务记录和已取消卡片及对应操作。
- 个人中心三个统计改接真实接口，点击后切换预约 Tab 并选中目标状态。
- 删除重复的预约占位路由，扩展预约和订单 API 类型。
- 更新小程序改造计划，运行类型检查、H5 与微信小程序构建。

## 任务 6：管理端预约工作台

- 扩展预约 API 类型和调用。
- 在现有预约页面增加四项统计、组合筛选、状态与操作列。
- 增加详情与操作时间线、客服改期、取消和面诊完成交互。
- 月历角标只统计待到店，日详情区分全部状态。
- 更新管理端改造计划，运行类型检查和生产构建。

## 任务 7：数据应用与三端联调

- 执行增量 SQL 前查询并记录预约表数据量，确认只删除预约域开发数据。
- 应用 `appointment_lifecycle.sql`，重新写入符合新模型的测试数据。
- 联调待预约 → 抽屉预约 → 待到店 → 改期/取消 → 重新预约。
- 联调订单核销进入服务记录、订单退款取消预约、后台面诊完成。
- 验证个人中心统计、TabBar 跳转、后台统计、列表、月历和权限。
- 汇总三个仓库改动与验证结果；代码提交和推送另按用户指令执行。
