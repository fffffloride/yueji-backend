# 预约场景关联实施计划

## 任务 1：服务端数据与规则

- 修改预约实体和创建 DTO，增加 `sceneType`、`orderId`。
- 增加订单预约资格查询；创建事务校验订单归属、状态和重复预约。
- 时段查询改为公开，创建和资格查询保留会员鉴权。
- 分页与日历批量补充订单号、商品名称。

- 扩展预约服务最小测试，执行预约测试和后端构建。

## 任务 2：管理端展示

- 扩展预约 API 类型。

- 更新管理端改造计划，执行类型检查和生产构建。

## 任务 3：小程序接入

- 接入动态时段和订单预约资格接口，提交时携带 `orderId`。

- 支付成功页和已支付订单卡片增加订单预约入口。
- 统一处理 TabBar 页参数及登录回跳，保留订单上下文。
- 首页、个人中心旧预约入口改到现有预约页。
- 更新小程序改造计划，执行类型检查、H5 与微信小程序构建并浏览器验收。

- 分别提交三个仓库的变更。
